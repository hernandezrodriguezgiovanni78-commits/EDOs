Unidad 6 - Resolución Numérica de EDOs
Metodos Numericos

Descripción

Proyecto realizado en Java para implementar y comparar dos métodos numéricos de resolución de ecuaciones diferenciales ordinarias (EDOs): Euler y Runge-Kutta de cuarto orden (RK4).

Métodos implementados

- Método de Euler: aproxima la solución de una ecuación diferencial utilizando pasos de tamaño definido.
- Método Runge-Kutta (RK4): calcula aproximaciones más precisas utilizando cuatro pendientes en cada paso.

Archivos del proyecto

- "MetodoEuler.java": implementación del método de Euler.
- "MetodoRungeKutta.java": implementación del método Runge-Kutta de cuarto orden.

Ejecución

1. Descargar o clonar este repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Ejecutar las clases "MetodoEuler" y "MetodoRungeKutta".
4. Revisar los resultados obtenidos en la consola.

Pruebas

Se realizaron pruebas con diferentes tamaños de paso:

- h = 0.1
- h = 0.05
- h = 0.01

Los resultados muestran que al disminuir el tamaño del paso se obtiene una aproximación más precisa.
